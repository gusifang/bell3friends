# Start here: interactive Bell/GHZ article

This folder is a Codex-ready project brief, not a completed website.

1. Read `THREE_FRIENDS_INTERACTIVE_SPEC.md` in full.
2. Read `Three friends and the impossible game.pdf` for the author's original narrative voice (note that its addendum contains superseded historical wording; the specification supplies the corrected facts).
3. Use `ghz_layout_1_triangle.svg` as the primary visual reference. `ghz_layout_2_pipeline.svg` and `ghz_layout_3_arena.svg` are alternatives.
4. Implement the complete application, including the tested mathematical engine and a reusable animated experimental scene.

Suggested Codex prompt:

> Implement the interactive article described in THREE_FRIENDS_INTERACTIVE_SPEC.md. Use the story PDF as narrative source and the triangular SVG as the visual reference. Build a complete runnable React/TypeScript/Vite project with tests and a README. Prioritize correct classical, cheating and GHZ simulations, and reuse a single SVG experiment scene across all chapters. Run tests and build before finishing.
